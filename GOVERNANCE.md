# Governance

Botanica uses a **single-maintainer** stewardship model.

| Topic | Policy |
|-------|--------|
| **Maintainer** | Michael A. Kuykendall ([@Michael-A-Kuykendall](https://github.com/Michael-A-Kuykendall)) |
| **Decision authority** | Maintainer is final arbiter for roadmap, architecture, data membership, and merges |
| **PR policy** | Unsolicited PRs are closed without merge; see [CONTRIBUTING.md](CONTRIBUTING.md) |
| **Ownership** | [CODEOWNERS](CODEOWNERS) points at the maintainer; branch protection may enforce review |
| **Licensing** | MIT OR Apache-2.0 for code; redistributable data sources attributed in MANIFEST (USDA PD, POWO/GBIF CC BY, etc.) |
| **Forks** | Permitted under the licenses; upstream inclusion remains maintainer discretion only |

No foundation, no elected board, no guaranteed review SLA on external patches.
